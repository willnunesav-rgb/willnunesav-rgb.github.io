Política de privacidade

Aplicativo: rclone Vitascience, de Will Nunes Audiovisual. Última atualização: 30 de outubro de 2026.

Quem usa

O aplicativo é de uso interno e é usado só por Will Nunes Audiovisual, com a conta willnunesav@gmail.com. Ele não é oferecido ao público.

Dados do Google que o aplicativo acessa

Com a autorização do próprio usuário, o aplicativo acessa o Google Drive dessa conta para enviar, listar e conferir os arquivos de backup das gravações de vídeo. Ele também lê o endereço de e-mail da conta, só para confirmar que o envio está indo para a conta certa.

Como os dados são usados

Os dados são usados apenas para fazer o backup e conferir que os arquivos chegaram inteiros ao Drive. O aplicativo não usa os dados para publicidade, não os vende e não os compartilha com terceiros. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Onde ficam

A autorização de acesso fica guardada só no computador do Will, no arquivo de configuração do rclone. Nenhum dado é enviado a servidores do aplicativo, porque ele não tem servidores próprios: a comunicação é direta entre o computador e o Google.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
