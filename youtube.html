Will YouTube Upload

Ferramenta interna de Will Nunes Audiovisual. Última atualização: 2 de novembro de 2026.

O que é

O Will YouTube Upload é um aplicativo de uso interno, sem fins comerciais, usado só por Will Nunes Audiovisual, editor de vídeo. Ele envia para o YouTube os vídeos editados por ele, nos canais em que o dono do canal autorizou o envio. Não é oferecido ao público.

Política de privacidade

Dados do Google que o aplicativo acessa

Com a autorização do dono do canal, o aplicativo usa a API de Dados do YouTube para enviar vídeos, thumbnails e legendas, ajustar título, descrição e visibilidade dos vídeos que ele mesmo enviou e ler o nome do canal, só para confirmar que o envio vai para o canal certo.

Como os dados são usados

Os dados são usados apenas para publicar e conferir os vídeos editados. O aplicativo não usa os dados para publicidade, não os vende e não os compartilha com terceiros. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Onde ficam

A autorização de acesso fica guardada só no computador do Will. Nenhum dado é enviado a servidores do aplicativo, porque ele não tem servidores próprios: a comunicação é direta entre o computador e o Google.

Como revogar

O dono do canal pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.
